# 和声进阶：附属和弦、三全音代理、借用和弦，以及几种"替代 V"的手法

这篇接着 [和弦进行入门](chord-progressions-guide.md) 写——那篇讲的是"调内"的和弦怎么排列才顺耳
（功能替代、五度圈、级进），这篇讲**怎么临时跳出调外**、给和声加变化，同时回答几个具体问题：
`4536251` 和五度圈的关系、为什么它流行、App 里有没有；以及 V9sus4、ivm6、"刹车和弦"这几种
替代 V 级的手法分别是什么。

## 0. 先分个类：这些手法都在解决同一个问题

一首歌如果自始至终只用调内的 7 个和弦，听久了会腻。下面三个概念都是"合法地引入调外和弦"的手法，
但**引入的理由不一样**，这是它们最本质的区别：

| 手法 | 引入调外和弦的理由 | 调外和弦要不要"解决" |
|---|---|---|
| **附属和弦**（secondary dominant） | 借用"目标和弦自己的属和弦"，临时加强推力 | 要——几乎总是紧接着解决到它推向的那个和弦 |
| **三全音代理**（tritone substitution） | 换一个音响效果更平滑（半音下行）的属和弦 | 要——本质还是属和弦，只是换了根音 |
| **借用和弦**（borrowed chord / modal mixture） | 从"同主音的另一个调式"（通常是关系不大的同主音小调）借一个和弦来换个"颜色" | 不一定——很多时候就是为了那个瞬间的色彩，不追求马上解决 |

三个手法用的都是"调外音"，但附属和弦、三全音代理是**功能性的**（服务于"推向某个目标"这件事），
借用和弦更多是**色彩性的**。分清这条界线，后面每个手法具体怎么用就都好理解了。

## 1. 附属和弦（Secondary Dominant）

[和弦进行入门 §5](chord-progressions-guide.md#5-次属和弦secondary-dominantchord-match-里偶尔插入的那个和弦)
已经讲过基础版本，这里补两点：

**基本原理**：V 能强烈地把你推向 I，那么调内任何一个和弦（除了 vii°，它本身太不稳定，没法当"临时的家"）
都可以有它自己的"临时属和弦"，写作 **V/x**（读作"five of x"）。比如 C 大调里：

- V/ii = A7（推向 Dm）
- V/IV = C7（推向 F——注意 C7 跟调内的 I 长得像但多了个降 7 音，是外来音）
- V/V = D7（推向 G，这是最常用的一个，因为"属和弦的属和弦"能造出一整串"越走越紧"的推力）

**扩展一步：不只是单个和弦，也可以是一整个临时的 ii-V**。比如不用单独一个 A7 推向 Dm，而是先来
一个 Em7♭5（Dm 的临时 ii）再接 A7（Dm 的临时 V），变成 `C - Em7♭5 - A7 - Dm - G - C`——这在爵士里
很常见，叫"套娃式属和弦链"（chain of applied ii-Vs / backcycling），本质是附属和弦的递归用法。

App 里 Chord Match 的 Progression 模式已经实现了最基础的版本（约 30% 概率插入单个次属和弦），
链式的临时 ii-V 目前没做。

## 2. 三全音代理（Tritone Substitution）

**核心原理**：任何属七和弦都可以换成"根音在三全音（增四/减五度）外的另一个属七和弦"，因为这两个
和弦共享同一组三全音音程——**只是 3 音和 7 音互换了角色**。

拿 C 大调的 `V7 = G7` 举例：G7 的 3 音、7 音是 B、F（三全音关系）。三全音外的 Db7 的 3 音、7 音正好
是 F、B（也就是升 C，等音于 Cb 的说法不常用，直接看做 F 和 B）——**同一对音，角色对调**。所以 Db7
能顶替 G7 去解决到 C，听感上"想解决"的推力几乎一样，但**根音的走法从"纯五度下行"变成了"半音下行"**
（G→C 是纯四度/五度关系，Db→C 只差半音），这就是三全音代理特有的、更"爬行式"的爵士味道。

记号通常写作 **subV7** 或者直接用降二级 **♭II7** 表示（因为三全音代理和弦的根音永远落在原属和弦
根音的降二级上）。最常见的用法是把标准的 `ii-V-I` 换成 `ii-subV-I`：

`Dm7 - G7 - Cmaj7` → `Dm7 - Db7 - Cmaj7`

低音线从 D→G→C（四度跳进）变成 D→Db→C（半音级进下行），这也是为什么三全音代理常常跟
[和弦进行入门 §4 机制三：级进链](chord-progressions-guide.md#机制三级进链stepwise-motion)扯上关系——
它能把原本"跳进"的和声，改造成"级进"的贝斯线。

三全音代理跟附属和弦的关系：**代理和弦本身也可以再被当成附属和弦来分析**（Db7 是 Gb 的临时 V），
但在实际使用里几乎没人这么想，都是直接当"G7 的替身"来用。

## 3. 借用和弦（Borrowed Chord / Modal Mixture）

**核心原理**：同一个主音的大调和小调（比如 C 大调 / c 小调）共享同一个主音，但音阶的 3、6、7 级不同。
"借用和弦"就是在大调歌曲里，直接借小调音阶算出来的和弦来用一下，换个"颜色"，不追求它有什么解决方向。

C 大调可借用的常见和弦（都来自 c 自然小调）：

| 借用和弦 | C 大调里的实际和弦 | 常见用法 |
|---|---|---|
| iv（小调下属） | Fm | 最常用的一个，经典"忧郁转折"色彩，常见于副歌前或结尾（Beatles《Something》） |
| ♭VI | Ab | 强烈的"戏剧性"色彩，常用在意外转折处，见第 5 节"刹车和弦" |
| ♭VII | Bb | 摇滚里很常见（"Mixolydian 味"），也是下面"后门进行"的关键角色 |
| ♭III | Eb | 相对少见，色彩浓烈，常见于抒情摇滚的高潮段 |
| ii°（减和弦） | Ddim | 很少单独用，多作为经过和弦 |

借用和弦和"移调到平行小调再回来"是一回事——本质上是临时向平行小调"借用"一个音色，
不涉及三全音代理那种"精确音程置换"的数学关系，纯粹是"这个和弦好听、放这儿刚好"。

## 4. 三者速查表

| | 来源 | 目的 | 典型标记 |
|---|---|---|---|
| 附属和弦 | 目标和弦自己的属和弦 | 加强推力 | V/ii、V/V |
| 三全音代理 | 原属和弦三全音外的另一个属七 | 换个更平滑的贝斯线 | subV7、♭II7 |
| 借用和弦 | 同主音小调（或其他调式）的对应和弦 | 换色彩，不为解决 | ♭VI、iv、♭VII |

## 5. `4536251` 和五度圈的关系，为什么这么流行，App 里有没有

把 `4536251` 翻成级数：**IV - V - iii - vi - ii - V - I**。拆开看根音怎么走（以 C 大调为例）：

```
F  →  G  →  Em →  Am →  Dm →  G  →  C
  +2度    -3度    +4度   +4度   +4度   +4度
（IV→V）        （iii→vi→ii→V→I，连续四步纯四度上行 = 纯五度下行）
```

关键发现：**从第 3 个和弦 iii 开始，后面 iii-vi-ii-V-I 这五个和弦，根音连续四步都是纯五度下行**——
这正是 [和弦进行入门 §4 机制二：五度圈链](chord-progressions-guide.md#机制二五度圈链circle-of-fifths)
里讲的那条规律，而且这条链子还恰好是 App 库里已有的那条 **`iii – vi – ii – V`（jazz turnaround）**
的完整延伸（多走一步落回 I）。前两个和弦 `IV-V` 则是常见的"下属到属"的功能性开场（相当于给这条
五度圈链加了一个两小节的引子）。

**为什么流行**，可以用两条独立的规律叠加来解释：

1. **五度圈本身就是最强的和声推力**——纯五度下行（或纯四度上行）的根音关系，是所有和弦进行里
   "拉力"最强的一种（正格终止 V→I 就是它最短的版本），`4536251` 把这种拉力连续用了四次，
   听感上会有一种"越走越收紧、必然走到 I"的宿命感。
2. **它顺路走遍了几乎所有调内和弦**——七个级数里用了六个（只跳过了不稳定的 vii°），比常见的
   四和弦进行（比如 `I-V-vi-IV`）信息量更大、更有"叙事感"，常被当作副歌或桥段的扩展版进行，
   本质上可以理解成"把经典的 `I-vi-ii-V` 或 `iii-vi-ii-V-I` 转身/加长了一节"。

**App 里现在没有这条完整的 7 和弦进行**——`FB_CHORD_PROGRESSIONS`（`web/fretboard.js`）里最接近的是
`iii – vi – ii – V（jazz turnaround）`（后 4 步）和 `I – IV – V – IV`（前两步的味道），但没有
把两段拼成一条 `IV-V-iii-vi-ii-V-I` 的完整条目。如果想把它加进 Chord Match 的 Progression 库，
告诉我一声，几行配置就能加上（参考 [和弦进行入门 §4](chord-progressions-guide.md#4-生成逻辑所有进行其实来自-3-4-个基础模型)
的分类方式，这条应该归进 `circle5` 类别）。

## 6. 三种"替代 V"的具体手法

### 属 9sus4 替代 V（V9sus4 for V）

**是什么**：把属和弦的 3 音（大三度，也是"想解决"那股拉力的来源）换成 4 音（挂留），再叠上 9 音，
变成 **1-4-5-♭7-9** 五个音的和弦，写作 **V9sus4**（C 大调里就是 G9sus4）。

**效果**：3 音是属和弦里"最想被解决"的那个音（导音级的紧张感来自它），换成 4 音之后，这股紧张感
被大幅削弱，和弦听起来更"悬空、柔和"，不再有"必须马上解决"的压迫感。这也是为什么它在福音
（gospel）、R&B、当代敬拜音乐（worship）里极其常见——很多歌干脆就让 V9sus4 悬停很久甚至直接
当作"准终止"使用，不一定真的解决回 3 音再落 I。

App 现状：`FB_CHORD_QUALITIES` 里已经有 **7sus4**（1-4-5-♭7，四音版），还没有加 9sus4（五音版，
多一个 9 音）——如果想在 Chord Match 里练这个具体和弦，也可以告诉我加上。

### 4 级小六和弦替代 V（ivm6 / "后门进行" backdoor progression）

这个是**借用和弦**的一个具体应用场景，爵士标准曲里很常见。正常的正格终止走 `ii-V-I`（属到主，
导音上行解决），"后门进行"则是借用小调的 iv，走 **`ivm6 - I`**（或者更完整的 `ivm7 - ♭VII7 - I`）
代替 `V-I`。

C 大调举例：iv 借用小调后是 Fm，加 6 音（D）变成 **Fm6 = F-Ab-C-D**。这个和弦里的 Ab（借来的
♭6 音）会半音下行解决到 G（I 的 5 音），跟正格终止里"导音 B 半音上行解决到 C"的拉力方向刚好相反
——**同样是半音解决，但方向反过来**，这就是"后门"这个名字的来源：不走正门（V 的导音上行），
从后面绕进来。因为色彩更柔和、不那么"宣告式"，很多抒情爵士标准曲（比如后半段避免用力度太强的
V-I）会用这招收尾。

### "刹车和弦"

这个说法比较口语化，不是教科书里的标准术语，我理解你大概率听到的是指：**该走向 V（或者已经让人
预期要走向 V→I 收尾）的地方，突然换成借来的 ♭VI**，制造一种"一脚急刹车"的效果——本质是"假终止"
（deceptive cadence，正常假终止是 V→vi）的加强版：**用调外的 ♭VI 代替调内的 vi**，因为 ♭VI 本身
就不属于这个调，听感上比"V→vi"那种"差一点点"的意外感更强烈、更戏剧化，像被一把拽住不让继续往前走。
常见于抒情歌曲高潮前的一个突然转折点。

如果你听到的"刹车和弦"是指别的东西（比如某个具体老师课上讲的某一个特定和弦，或者指别的效果），
把上下文/是哪个视频发我，我再对着核实调整这部分。
