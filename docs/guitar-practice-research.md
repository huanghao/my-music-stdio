## 一、完整分级体系

### 分级说明

采用 6 级体系，参考 JustinGuitar Grade 1-9、RGT、Trinity 考级及社区共识综合制定。  
时间估算假设每天练习 30-60 分钟，因人而异差异极大。

```
L1 零基础  ──▶  L2 入门  ──▶  L3 初级  ──▶  L4 中级  ──▶  L5 高级  ──▶  L6 专业/大师
 0~1月           1~6月        6月~2年        2~5年          5~10年         10年+
```

---

### L1 零基础（Absolute Beginner）

**标志性状态：** 第一次拿起吉他，手指按弦会痛，出不了清音  
**目标：** 能弹出第一首简单歌曲，不再怕吉他

| 维度 | 内容 |
|------|------|
| 技术 | 正确持琴姿势；左手手型；右手拨弦基础；按出单音（不闷弦） |
| 和弦 | Em、Am（双指和弦） |
| 节奏 | 四分音符扫弦 |
| 乐理 | 吉他各部件认识；6根弦的名字（EADGBE） |
| 耳训 | 无 |

---

### L2 入门（Foundation）

**标志性状态：** 能弹完几首简单歌曲，和弦切换还慢但不中断  
**目标：** 建立基础和弦库，能跟着歌弹完一首歌

| 维度 | 内容 |
|------|------|
| 技术 | 完整开放和弦按法；扫弦（下扫为主）；手指独立性练习 |
| 和弦 | G、C、D、Em、Am、E、A（7个基础开放和弦）；和弦切换开始流畅 |
| 节奏 | 基础扫弦型（下下上下上）；能配合慢速节拍器 |
| 音阶 | 单弦音阶（chromatic 热身）；A小调五声第1把位（能弹上下行） |
| 乐理 | 12个音名（C D E F G A B + 升降号）；半音/全音概念；什么是大调/小调 |
| 耳训 | 分辨大和弦和小和弦的「感觉」 |
| 参考曲目 | 民谣简单歌曲；Wish You Were Here（前奏）；Knockin' on Heaven's Door |

---

### L3 初级（Beginner+）

**标志性状态：** 横按和弦虽然痛苦但能发出声；开始用五声即兴  
**目标：** 横按解锁，掌握五声音阶基础，能做简单即兴

| 维度 | 内容 |
|------|------|
| 技术 | **横按（大横按）**：F型、B型；**击弦/勾弦（hammer-on/pull-off）**：基础连音；**推弦**：全音推弦；**揉弦**：简单揉弦 |
| 和弦 | CAGED系统入门（了解C型/A型/G型/E型/D型可移调）；Bm、F等常见横按和弦 |
| 节奏 | 切分节奏基础；扫弦加入哑音（× 符号）；Fingerpicking入门（Travis picking） |
| 音阶 | **五声音阶全5个把位**（重点）；连接相邻两个把位；一弦三音 |
| 乐理 | **自然大调音阶**；调（Key）的概念；I II III IV V VI VII 级和弦；平行大小调 |
| 耳训 | 辨别纯五度/纯四度；大调/小调音阶听感区分 |
| 参考曲目 | Purple Haze（单音 riff）；Wonderful Tonight（节奏）；Sweet Home Chicago（蓝调入门）；Smoke on the Water |

---

### L4 中级（Intermediate）

**标志性状态：** 横按流畅，能在五声内有点感觉地即兴，开始听懂调式  
**目标：** 建立完整的音阶/调式体系，技术趋于稳定流畅

| 维度 | 内容 |
|------|------|
| 技术 | **精准推弦**（半音/全音/1.5音）；**揉弦风格**（classic rock / blues / vibrato arm）；**双手点弦**基础；**交替拨弦（alternate picking）**流畅；**跨弦拨弦**；**扫弦（sweep picking）**基础；**Legato（连音）跑动** |
| 和弦 | 7th/maj7/m7/dom7/dim/aug 和弦；不同把位同一和弦（CAGED完整理解）；转位和弦基础；Slash chords |
| 节奏 | 切分/附点节奏流畅；6/8拍；混合节奏型；Fingerpicking高级型 |
| 音阶 | **自然大调7个调式**（Ionian/Dorian/Phrygian/Lydian/Mixolydian/Aeolian/Locrian）；**蓝调音阶**；**混合五声**（Major pentatonic + Minor pentatonic混用）；音阶三度/六度音程练习 |
| 乐理 | **功能和声**（T/S/D）；**二五一（II-V-I）**进行；**转调基础**；**音程理论**（所有音程）；**和弦代替**基础 |
| 耳训 | **音程识别**（全部12个音程）；**和弦性质识别**（maj/min/dom7/maj7/m7）；开始能扒谱（简单旋律） |
| 参考曲目 | Comfortably Numb 独奏；Sultans of Swing；Black（Pearl Jam）；Eruption（Van Halen）入门段 |

---

### L5 高级（Advanced）

**标志性状态：** 有个人风格雏形，能在多种调式下即兴，技术相当流畅  
**目标：** 形成个人音乐语言，掌握复杂技术和高级乐理

| 维度 | 内容 |
|------|------|
| 技术 | **扫弦（sweep picking）**流畅（3/4/5/6弦琶音）；**Economy picking**；**Hybrid picking（混合拨弦）**；**Tapping（点弦）**流畅；**String skipping（跳弦）**；**Whammy bar技巧**；精细的**动态控制**（音量/音色）；**节奏精准度**（机器级别） |
| 和弦 | 爵士和弦（9th/11th/13th/altered）；Drop 2/Drop 3 和弦；多声部演奏 |
| 节奏 | **Odd time signatures**（5/4、7/4、7/8）；复合节奏（polyrhythm）；Groove研究 |
| 音阶 | **Harmonic minor / Melodic minor 及其调式**；**Diminished音阶**；**Whole tone音阶**；**Bebop音阶**；**复合音阶**即兴（在同一段落换音阶） |
| 乐理 | **Reharmonization（和声再配置）**；**Modal interchange（调式借用）**；**爵士和声**（二五一、转调、substitution）；**对位**基础；**和声分析** |
| 耳训 | **和弦进行听辨**（能扒大多数歌）；**调式感**（听出是Dorian还是Mixolydian）；**节奏听辨**（复杂节奏型） |
| 参考曲目 | Eruption（Van Halen完整版）；Cliffs of Dover（Eric Johnson）；Midnight（Joe Satriani）；爵士标准曲（Autumn Leaves等）入门 |

---

### L6 专业/大师（Professional / Master）

**标志性状态：** 有成熟个人风格，能作曲编曲，舞台经验丰富  
**目标：** 这不是一个终点，而是持续演化的状态

| 维度 | 内容 |
|------|------|
| 技术 | 所有技术炉火纯青；**速度不是目标，表达才是**；深度掌握某一风格的精髓技法 |
| 和弦/编曲 | 能在实时演奏中做复杂和声；作曲/编曲；带乐队 |
| 即兴 | 完全的音乐直觉；**跨风格**融合；"忘掉音阶只想旋律" |
| 乐理 | 乐理是工具而非目标；能灵活运用各种理论解决音乐问题 |
| 耳训 | 近乎完美的相对音感；能听清楚任何音乐并还原 |
| 标志人物 | Jimi Hendrix、Eric Clapton（布鲁斯）；Steve Vai、Joe Satriani（摇滚技术）；Pat Metheny（爵士）；Tommy Emmanuel（指弹）；John Petrucci（金属）|

## 二、各技能方向深度分析

### 2.1 技术类

#### 推弦（String Bending）

**为什么难：**
- 需要精准控制音高（目标音高是具体的音，不是随便拉高）
- 需要三根手指协作用力（不是单指）
- 需要手腕转动而非只靠手指
- 需要维持推弦后的音高稳定（不回落）

**常见错误：**
- 只用一根手指推，力量不够导致音高不足
- 推到位但马上松，无法维持
- 推弦时其他弦被触碰发出杂音
- 不知道目标音高是什么，靠感觉随便推

**标准练习方法：**
1. **参照音法**（最重要）：先拨目标音，再推弦听是否到位，用耳朵而不只用眼睛
2. **慢推法**：慢速推上去，数1-2-3，到目标后维持3-5秒
3. **Push & Release**：推上去后再慢慢放回来，保持音准控制
4. **调音器验证**：用调音器检查是否精准到达半音/全音

**调音器辅助 vs 耳朵辅助：**
- 调音器好处：直观，不会骗自己
- 耳朵好处：更接近实际演奏场景，能训练耳肌肉记忆
- 建议：初期用调音器建立概念，中期主要靠耳朵，定期用调音器校准

#### 揉弦（Vibrato）

**分类：**
- 古典揉弦：手指上下移动（不常见于摇滚）
- 横向揉弦（摇滚主流）：推弦-回落交替，手腕转动
- 宽泛 vs 窄小揉弦：取决于音乐风格

**衡量指标：**
- 速率（Rate）：每秒几个循环，通常 4-7Hz
- 深度（Depth）：音高偏移量，通常 ±20-50 cents
- 均匀性：每个循环的深度是否一致
- 时机：什么时候开始揉弦（马上 vs 延迟进入）

#### 横按（Barre Chords）

**为什么是大多数初学者的天花板：**
- 食指需要同时按压6根弦且每根都清晰
- 需要大量指力积累（通常需要几个月）
- 手型和手腕角度要求精确

**练习策略：**
1. 只按前两弦开始，逐步加弦
2. 找到"甜点"位置（靠近品格金属丝）
3. 先练A型横按（只有5根弦），比F型更友好
4. 一分钟横按练习：只按不弹，保持1分钟，每天做

#### 交替拨弦（Alternate Picking）

**核心问题：不是快，是均匀**  
大多数人单向拨弦很快，但交替拨弦慢很多，原因是拨弦方向切换时有延迟。

**Troy Grady "Cracking the Code" 关键发现：**
- 拨片逃逸方向决定了哪种拨弦更高效
- "Downward Slanting" vs "Upward Slanting"
- 不同吉他手有不同的"主导逃逸方向"（Eric Johnson 向上，Paul Gilbert 双向）
- 强行双向均匀往往比找到自然逃逸方向更难

**实践建议：**
- 先找到自己的自然拨弦方式
- 用节拍器从极慢开始（60 BPM 八分音符）
- 不要急于求快，速度是均匀性的副产品

### 2.2 乐理类

#### CAGED 系统

**核心思想：** 整个指板只有5种基本和弦形状，所有和弦都是这5种形状的移调

```
开放和弦原型：C型  A型  G型  E型  D型
可以推导出：   同名和弦在指板上的5个位置
```

**实用价值：**
- 知道任何一个和弦在指板上所有位置
- 理解音阶把位和和弦把位的关系
- 快速找到目标音区的和弦

**常见误区：**
- 只把CAGED当成和弦系统，忽略它也定义了音阶位置
- 死记硬背形状，而不理解音程关系

#### 调式（Modes）

**本质：** 同一个音阶从不同音开始，得到不同的"情绪"

| 调式 | 对应级数 | 情绪 | 常用场景 |
|------|---------|------|---------|
| Ionian | I级 | 明亮、快乐 | 流行、大调歌曲 |
| Dorian | II级 | 忧郁但不悲伤 | 蓝调摇滚、Celtic音乐 |
| Phrygian | III级 | 阴暗、西班牙风格 | 金属、弗拉门戈 |
| Lydian | IV级 | 神秘、梦幻 | 电影配乐 |
| Mixolydian | V级 | 蓝调感、摇滚感 | 摇滚、蓝调 |
| Aeolian | VI级 | 悲伤、自然小调 | 大多数摇滚 |
| Locrian | VII级 | 极度不稳定 | 很少用 |

**学习顺序建议：**  
Dorian → Mixolydian → Aeolian → Phrygian → 其他

#### 功能和声（Functional Harmony）

**三大功能：**
- **Tonic（T）**：稳定，回家感，I级（也可以VI级）
- **Subdominant（S）**：过渡，IV级（也可以II级）
- **Dominant（D）**：张力，解决到I级，V级（通常是V7）

**二五一（II-V-I）进行：**  
爵士的基石，也在流行/摇滚中大量出现  
`Dm7 - G7 - Cmaj7`（C大调中的IIm7-V7-Imaj7）

## 三、现有软件/方法调研

### 3.1 主流软件对比

| 软件 | 平台 | 交互方式 | 核心优势 | 主要不足 |
|------|------|---------|---------|---------|
| **Yousician** | iOS/Android/PC | 麦克风实时检测 | 音符/和弦实时反馈；进度系统完整；游戏化 | 延迟高影响体验；判断机制死板（扒音不准）；订阅贵 |
| **Rocksmith+** | PC/Console | 吉他直接Line-in | 真实演奏感；动态难度；海量曲库 | 需要专业声卡；曲库方向偏摇滚；订阅制 |
| **GuitarTuna** | iOS/Android | 麦克风 | 准确调音；和弦图库 | 功能单一，主要是调音 |
| **JustinGuitar** | iOS/Android/Web | 视频为主 | 课程质量极高；结构化体系；完全免费；社区强 | 主动反馈弱；没有实时音频分析 |
| **Fender Play** | iOS/Android | 视频为主 | 制作精良；歌曲导向；入门友好 | 主动反馈弱；订阅贵 |
| **EarMaster** | iOS/PC | 键盘/MIDI | 耳训最系统 | 和吉他练习完全脱节；界面老旧 |
| **ToneLib Jam** | PC | 音频 | 伴奏带；Amp模拟 | 练习引导弱 |
| **Amazing Slow Downer** | iOS/Android | 回放 | 降速不变调；扒谱神器 | 只是工具，没有引导 |

### 3.2 Rocksmith+ 值得学习的设计

- **Riff Repeater**：选择歌曲中任意片段，循环练习，可降速到50%，精准到小节
- **Dynamic Difficulty**：根据你的演奏准确率自动调整难度（减少音符或增加）
- **Score Attack**：把演奏变成竞技得分，促进反复练习
- **Missions系统**：明确的短期目标（今天完成3个使命）

### 3.3 Yousician 值得学习的设计

- **即时音符检测**：你弹的音对不对立刻显示
- **进度树**：技能分支可视化
- **每日任务**：保持练习习惯的推送机制
- 不足：音符识别延迟 + 准确率让人沮丧（吉他音频识别本身就难）

### 3.4 JustinGuitar 值得学习的方法论

#### "一分钟变换"（One-Minute Changes）
两个和弦之间计时1分钟，数切换次数，记录下来。每天练，看曲线上升。  
**关键洞察**：大多数人切换慢是因为**离弦太早**而不是按弦太慢。

#### 分级课程结构
每一个 Grade 有：热身 → 和弦 → 技术 → 节奏 → 理论 → 歌曲 的完整体系，而不是随机练习。

#### "模块化"练习
把每次练习时间切成固定块：  
`10min 热身 + 10min 技术 + 10min 音阶/即兴 + 10min 曲目`

### 3.5 社区经验精华（Reddit/YouTube/论坛）

**关于推弦：**
- 最推荐：先拨目标音→再推弦→用耳朵对比（而非只看调音器）
- Paul Gilbert方法：慢速推弦，数1-2-3推到顶
- 常见错误：推弦用单指力气，应该三根手指一起用

**关于速度：**
- "慢是快的基础"几乎是所有大师的共识
- Rick Beato："如果你弹不慢，你根本没有真正掌握这段"
- 节拍器不要一直加速，有时故意放慢到舒服速度的50%重新审视动作

**关于即兴：**
- 初期五声音阶是最高性价比的学习
- 中期最大障碍：只会"跑音阶"，没有"乐句感"（phrase）
- 解决方法：大量听分析喜欢的吉他手的乐句，模仿具体乐句而不是技术

**关于耳训：**
- 边弹边唱（即使不会唱歌），是建立乐理/耳训/技术三位一体最有效的方法
- 不推荐单独做耳训App，效果远不如在乐器上做

## 四、软件功能设计思路

### 4.1 核心设计理念转变

**现有大多数软件模式（回合制）：**
```
软件出题 → 你演奏 → 软件判断 → 下一题
```

**更好的模式（持续陪练/Always-On）：**
```
软件持续听 → 实时显示发生了什么 → 你根据反馈主动调整
```

这更像一个「看得见的耳朵」，而不是出卷老师。  
用户自主权更高，适合主动型学习者。

---

### 4.2 功能模块设计

#### A. 推弦/揉弦分析器

**核心体验：**
```
目标：D4（全音推弦 from C4）

  D4 ─────────────────── 目标线（绿色）
  C#4
  C4 ─────────────────── 起始线（灰色）

  实时音高曲线 ：
  C4 ──/─────────── D4（推到位）
              ↑
        推弦轨迹

  [准确度 94%]  [维持时长 2.3s]  [振动稳定性 ●●●○○]
```

**功能细节：**
- 实时音高折线图（时间轴上的音高曲线）
- 推弦精度：距目标音高多少 cents（+/-）
- 维持时长：推到目标区间（±20 cents）后能保持多久
- **揉弦模式**：检测揉弦的频率（Rate）和深度（Depth）
  - 显示揉弦的"波形"
  - 对比目标范围（5-7Hz，±30 cents 为健康揉弦）
- 历史记录：这周推弦准确度曲线

**交互特点：持续监听，不需要点"开始"**

---

#### B. 实时音符 HUD（音符识别叠加层）

用户演奏时，屏幕角落显示：

```
┌─────────────────────────────┐
│  当前音：G3                  │
│  在指板：6弦 3品             │
│  在 G大调：根音（I）         │
│  在 G五声：✓ 框内音          │
│  距上次音：纯四度 ↑           │
└─────────────────────────────┘
```

**用途：**
- 初学者：边弹边知道自己在弹什么音
- 中级：理解音符的"功能"和"调式位置"
- 即兴练习：看自己是否在设定的音阶内

**实时性要求：**  
延迟需要 <50ms 才有实用价值，否则音符都过了才显示没意义。  
我们目前的音高检测延迟需要评估。

---

#### C. 和弦切换计时器（改进版 One-Minute Changes）

**基础功能：**
- 设定两个目标和弦
- 麦克风持续监听，检测到和弦变换就计一次
- 实时显示：当前次数、剩余时间

**增强功能：**
- 错误切换检测（切换成了错误的和弦，显示红色警告）
- 历史记录曲线（这周从多少次进步到多少次）
- 速度感知：每次切换之间的时间间隔，显示是否越来越快

**设计挑战：**
和弦检测比单音检测难得多，需要考虑检测准确率问题。  
建议：先用 chroma 特征做粗判断，不需要100%准确，只要能分辨"你在弹G还是C"就够用。

---

#### D. 音阶/即兴自由练习模式

**场景：** 用户设定"我要练 A小调五声第2把位"，然后自由弹

**软件做什么：**
```
[指板可视化]
高亮该把位的所有音符

实时反馈：
✓ A  ✓ C  ✓ D  ✗ D# (不在音阶内)  ✓ E

练习结束后统计：
- 你用了哪些音（A:35次 C:12次 D:8次 E:20次 G:15次）
- 你没用的音（A没用高八度的那个）
- 是否有习惯性的音（你总是从E开始）
```

**价值：** 让用户看到自己的"即兴习惯"，发现盲区

---

#### E. 节奏准确度分析

**核心显示：**
```
拍点   |  1  |  2  |  3  |  4  |
误差   | -10 | +5  | -25 | +3  |  单位：毫秒

总体评价：第3拍有提前拍弦的习惯（-25ms）
```

**功能：**
- 设定BPM，开启内置节拍器
- 麦克风检测你的拨弦时间点
- 计算相对于节拍的超前/滞后毫秒数
- 累积发现规律性问题（某拍总是偏早或偏晚）

**不同于现有节拍器App的点：**  
现有App：给你一个节拍器（被动）  
我们的：听你弹，告诉你偏差在哪（主动反馈）

---

#### F. 耳训 + 吉他结合（去掉纯软件耳训的割裂感）

**音程演奏确认：**
- 软件播放一个音（440Hz = A4）
- 你在吉他上弹出它的纯五度（E5）
- 实时确认是否正确
- 进阶：软件只说"上行纯五度"，你在吉他上找到并弹出

**和弦性质回应：**
- 软件播放一个和弦
- 你在吉他上弹出相同性质的和弦（不限把位）
- 这训练的是"听到然后在乐器上重现"，而不是纸上谈兵

---

#### G. 推弦专项练习（针对第1个问题的完整设计）

**练习流程：**
1. 选择目标推弦类型（半音/全音/1.5音）
2. 软件提示起始音和目标音（并播放目标音供参考）
3. 用户推弦
4. 实时显示音高曲线，推弦过程可视化
5. 判断是否到达目标区间，显示准确度和维持时长
6. 10次为一组，显示平均准确度

**难度递进：**
- 入门：半音推弦（最容易控制）
- 中级：全音推弦
- 高级：1.5音推弦；多弦同时推弦
- 专业：预推弦（pre-bend，先推再拨弦）

---

### 4.3 交互模式总结

| 交互特性 | 现有软件 | 我们可以做的 |
|---------|---------|------------|
| 反馈时机 | 演奏完后（回合制） | 演奏中实时 |
| 触发方式 | 点按钮开始 | 拿起吉他就开始（麦克风常驻） |
| 反馈颗粒度 | "对/错" | "偏差多少、在哪个维度" |
| 用户控制权 | 软件主导练什么 | 用户自由探索，软件只显示信息 |
| 情境感知 | 无 | 知道你在练什么，给对应提示 |
| 历史追踪 | 得分/进度条 | 具体技术指标的时间曲线 |

---

### 4.4 技术可行性评估

| 功能 | 关键技术 | 难度 | 当前状态 |
|------|---------|------|---------|
| 推弦/揉弦分析 | 精准音高检测（pitch tracking）| 中 | 已有音高检测基础 |
| 实时音符HUD | 单音识别 + 低延迟 | 中 | 已有音高检测 |
| 和弦切换计时 | 和弦识别（准确率要求不高）| 中高 | 已有chroma分析 |
| 音阶即兴追踪 | 单音识别 + 音阶匹配 | 低 | 可在现有基础上做 |
| 节奏准确度 | onset detection（拨弦时间点）| 中 | 需要新增 |
| 耳训吉他结合 | 单音识别 | 低 | 已有基础 |

## 五、待讨论 / 需要 Review 的问题

1. **分级体系**：6级是否合适？各级的时间估算是否合理？
2. **功能优先级**：哪个功能对你当前最有价值（推弦分析？节奏分析？音阶追踪？）
3. **实时性要求**：我们的音高检测延迟大概是多少？是否满足"实时HUD"的需求？
4. **和弦检测准确率**：和弦切换计时器依赖和弦识别，当前准确率如何？
5. **Always-On 模式**：麦克风持续监听对电池/CPU 的影响，以及用户隐私感受
6. **推弦练习**：是否也要设计揉弦的专项练习？两者可以合并还是分开？

## 附录：主流吉他分级参考体系介绍

### A. JustinGuitar Grade System

**机构：** Justin Sandercoe 个人创建，网站 justinguitar.com  
**成立：** 2003年（网站），课程体系持续迭代至今  
**性质：** 免费在线课程，非官方考级，无证书  
**受众：** 主要针对电吉他/民谣吉他，风格偏流行/摇滚  

**分级结构：**

| 阶段 | Grade | 大致时长（每天30-60分钟）|
|------|-------|----------------------|
| Beginner | Grade 1-3 | 3-12个月 |
| Intermediate | Grade 4-6 | 1-3年 |
| Advanced | Grade 7-9 | 3年+ |

**每个 Grade 包含：**
- 必学和弦/技术
- 指定练习曲目（流行歌曲）
- 理论知识点
- 推荐练习时长分配

**为什么重要：** 社区公认度极高，是英文世界最推荐的免费吉他课程。Reddit r/guitarlessons 几乎所有初学问题的标准回答都是"去学 JustinGuitar"。他的分级体系非常务实，以"你能做到什么"定级而非考试。

**与我们的关系：** 本文档的 L2-L4 级别内容大量参考了 JustinGuitar 的课程框架。他的「一分钟变换」练习法也是值得借鉴的软件功能。

---

### B. ABRSM（英国皇家音乐学院联合委员会）

**全称：** Associated Board of the Royal Schools of Music  
**机构：** 英国四所皇家音乐学院联合成立（1889年），总部伦敦  
**性质：** 官方考级，全球认可，颁发证书  
**受众：** 以古典音乐为核心，吉他考级以**古典吉他**为主  

**分级结构：**

```
Initial → Grade 1 → Grade 2 → ... → Grade 8
             ↑                          ↑
         绝对初学               约等于音乐学院入学水平
```

再往上还有 Diploma 系列：DipABRSM → LRSM → FRSM（教学/演奏方向）

**每次考试包含：**
- **演奏曲目**：考官指定曲目列表中选3首
- **音阶/琶音**：考官随机抽查
- **视奏**：当场看谱演奏
- **听觉测试（Aural）**：唱出音程、拍手节奏等

**Grade 大致对应：**

| Grade | 能力描述 | 换算 |
|-------|---------|------|
| 1-2 | 能演奏简单旋律，基础和弦 | 相当于我们的 L2 入门 |
| 3-5 | 初步技术，简单到中等难度作品 | 相当于 L3-L4 |
| 6-8 | 较复杂作品，有一定音乐诠释能力 | 相当于 L4-L5 |
| Diploma | 专业演奏/教学水平 | 相当于 L6 |

**局限性：** ABRSM 体系高度偏向古典音乐和视奏能力，对摇滚/流行吉他手参考价值有限。"Grade 5 理论考试"是个门槛（Grade 6-8 考试要求先通过 Grade 5 乐理）。

**与我们的关系：** 主要参考其对"技术能力分级"的思路，但具体内容不直接适用（古典 vs 流行/摇滚）。

---

### C. Trinity College London

**机构：** Trinity College London，1872年成立，总部伦敦  
**性质：** 官方考级，与 ABRSM 是主要竞争对手，全球认可  
**受众：** 提供两条轨道，比 ABRSM 更贴近流行音乐：

- **Classical Guitar**：古典吉他，结构类似 ABRSM
- **Rock & Pop Guitar**：电吉他/民谣吉他，流行摇滚风格（**更相关**）

**Rock & Pop Guitar 分级：**

```
Initial → Grade 1 → Grade 2 → ... → Grade 8
```

**与 ABRSM 的主要区别：**

| 对比项 | ABRSM | Trinity Rock & Pop |
|--------|-------|--------------------|
| 风格 | 古典为主 | 流行/摇滚 |
| 曲目 | 固定曲目列表 | 更多自选空间 |
| 视奏 | 必考 | 可用即兴替代（部分等级）|
| 理论考试 | Grade 6+需先通Grade 5理论 | 无此前置要求 |
| 整体氛围 | 较保守 | 较现代 |

**考试内容（Rock & Pop）：**
- 演奏曲目（3首，从曲库中选）
- 技术练习（音阶等）
- 音乐知识（口头问答）
- 听觉/即兴（视级别而定）

**与我们的关系：** Trinity Rock & Pop 的分级对流行/摇滚吉他手更有参考价值，但对非考级用户仍然较"学院派"。其 Grade 1-8 的递进逻辑可以参考。

---

### D. RGT（英国吉他教学注册机构）

**全称：** Registry of Guitar Tutors  
**机构：** 1996年成立，UK，专注于吉他教学  
**性质：** 官方考级，颁发证书，但知名度低于 ABRSM/Trinity  
**独特之处：** 这是**专门为吉他设计**的考级体系，不是通用音乐考级延伸到吉他  

**提供的吉他方向：**
- Electric Guitar（电吉他）
- Acoustic Guitar（民谣吉他）
- Classical Guitar（古典吉他）
- Bass Guitar（贝斯）

**分级结构：**

```
Preliminary → Grade 1 → Grade 2 → ... → Grade 8
                                              ↓
                                    Performance Certificate
                                    Teaching Certificate
```

**考试内容（以 Electric Guitar 为例）：**
- 演奏曲目
- 技术练习（Riffs/Licks/音阶）
- 和弦知识
- 即兴演奏（高等级）
- 乐理知识

**Grade 大致对应（Electric Guitar）：**

| Grade | 能力描述 |
|-------|---------|
| 1-2 | 开放和弦，基础扫弦，简单旋律 |
| 3-4 | 横按入门，五声音阶，基础效果器 |
| 5-6 | 调式理解，推弦/揉弦，即兴基础 |
| 7-8 | 复杂技术，高级乐理，风格化演奏 |

**为什么重要：** RGT 是唯一一个专门为吉他手（而非通用音乐学生）设计的体系，因此在技术内容上更贴近实际演奏需求（包括效果器知识、风格特征等）。

**与我们的关系：** RGT Electric Guitar 的分级内容是参考价值最高的，尤其是对各等级"技术要求"的描述。
