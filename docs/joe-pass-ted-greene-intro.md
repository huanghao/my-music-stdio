# 独奏爵士吉他（Chord Melody）全景：门类背景、谱系必知乐手，以及 Joe Pass、Ted Greene 深度介绍

这篇本来只打算介绍 Joe Pass 和 Ted Greene 两个人，但这两位其实是**一整条谱系**里最靠后的两个代表人物，不
了解前面的人，容易把他俩的成就当成"凭空出现的天才"，而不是一门技艺几十年逐步积累的结果。所以这篇先讲清楚
这个门类本身是什么、这条谱系上必须知道的人有哪些，再深挖 Joe Pass 和 Ted Greene 这两位。这门技艺的地基
（shell voicing / 壳和弦）单独写在 [shell-chords-guide.md](shell-chords-guide.md)，这篇文末会接回去。

## 1. 这是个什么门类

**Chord Melody（和弦旋律）/ Solo Jazz Guitar（独奏爵士吉他）**：一把吉他同时弹出**旋律、和声、低音**三个声部，
不依赖乐队里的钢琴/贝斯/鼓手，自己就能撑起一整首曲子的演出。

这门技艺之所以要"发明"出来，是因为吉他和钢琴的先天结构不一样：钢琴一双手天然就能同时按旋律、和弦、低音，这是
它的乐器结构决定的；吉他在乐队里的传统角色是**伴奏/节奏乐器**（comping），旋律交给管乐器或人声，吉他手很长
一段时间里没有"一个人扛下所有声部"这个念头。Chord Melody 这条谱系，就是一群吉他手不断想办法把钢琴能做到的事
"翻译"到六根弦上的过程——George Van Eps 甚至直接把自己的技巧叫"lap piano"（膝上钢琴），说的就是这个企图心。

## 2. 谱系时间线：从 Django 到当代传人

| 年代 | 乐手 | 为什么必须知道他 |
|---|---|---|
| 1930s-40s | **Django Reinhardt**（1910-1953） | 吉普赛爵士（Gypsy Jazz）奠基人，用半音阶乐句、飞快琶音和创新和弦把吉他确立成能"领奏"的乐器，是后面所有人共同的精神源头 |
| 1930s-40s | **Charlie Christian**（1916-1942） | 电吉他先驱，把吉他从"扫弦伴奏"变成能像萨克斯一样吹单音线条领奏的乐器，Bebop 吉他语言的开创者 |
| 1930s-90s | **George Van Eps**（1913-1998） | **公认的 chord melody 之父**。发明 7 弦吉他（在低音端加一根弦），能在弹和弦旋律的同时弹出独立的走动低音，自称"lap piano"，直接启发了后面几乎所有人 |
| 1950s | **Barney Kessel / Tal Farlow / Johnny Smith / Jimmy Raney** | 战后 Bebop 一代，把吉他坐实成能跟萨克斯、小号平起平坐的即兴乐器，确立了现代爵士吉他的和声词汇 |
| 1960s | **Wes Montgomery**（1923-1968） | 用大拇指代替拨片弹出温暖厚实的音色，标志性的八度（octaves）单线奏法影响了几乎每一位之后的爵士吉他手 |
| 1960s-80s | **Lenny Breau**（1941-1984） | 在 6 弦基础上加一根高音弦（不是 Van Eps 那种加低音弦），泛音（harmonics）技巧登峰造极，被认为是吉他上最接近"钢琴式和声自由度"的人 |
| 1960s-90s | **Joe Pass**（1929-1994） | 本文重点之一，见第 3 节 |
| 1960s-2000s | **Ted Greene**（1946-2005） | 本文重点之一，见第 4 节 |
| 1950s-2010s | **Ed Bickert**（1932-2019） | 内声部（inner voice）声部连接极其考究的加拿大吉他手，和弦选择被同行形容为"每一个都是当下最好的选择"，是 drop2/drop3 之外的另一条声部连接思路 |
| 1950s-2020s | **Bucky Pizzarelli**（1926-2020）与 **Howard Alden**（b.1958） | 延续 Van Eps 的 7 弦香火，把"加低音弦"这条技术路线一直带到现在 |
| 1980s-至今 | **Martin Taylor**（b.1956） | 当代最活跃的独奏爵士吉他传人，深受 Bill Evans、Art Tatum 两位钢琴家启发，把 chord melody 编成系统化的"七步法"教材，是这条谱系里教学资料最新、最好上手的一位 |

## 3. Joe Pass 深度介绍

### 生平：从毒瘾到大师

Joe Pass，本名 Joseph Anthony Jacobi Passalacqua，1929 年生于新泽西，在宾夕法尼亚 Johnstown 的西西里移民
家庭长大。9 岁生日收到人生第一把吉他（17 美元的 Harmony 牌），此后疯狂练习，14 岁就已经能靠弹琴挣得比当
钢铁工人的父亲还多的钱。

他的职业生涯在二十出头时被**严重的海洛因成瘾**打断：多次被捕，一次住院长达四年，后来搬到新奥尔良为脱衣舞
俱乐部弹 bebop 谋生（那段时期毒品唾手可得，他自己形容那段经历是一场"精神崩溃"），整个 1950 年代大部分时间
在监狱和戒毒之间反复。1960 年底，他走进 Synanon——加州圣莫尼卡的一家戒毒康复机构，进去的时候身上只有 13
美分、没有吉他，靠在康复机构里组建的乐队重新找回了音乐。两年半后康复出来，1962 年发行的合辑
**《Sounds of Synanon》**是他的录音室处子秀，也是他向爵士乐界证明自己实力和康复成果的起点。

### 风格拆解

早期风格受 Django Reinhardt（吉他）和 Charlie Parker（萨克斯）影响，以快速的单音线条和流畅的旋律感见长。
真正让他留名的是后来转向独奏吉他之后发展出的 chord melody 打法：

- 放弃拨片改用**指弹（fingerstyle）**，因为指弹能同时够到旋律音、和弦音、低音，拨片做不到这种"一把吉他当
  三件乐器弹"的效果。
- 同时进行**旋律 + 和声对位（melodic counterpoint）+ 走动低音（walking bass）**——三条线同时在指板上进行，
  听感上像不止一把吉他在响。
- 大量运用**和弦转位（chord inversions）**做平滑的声部连接（voice leading），乐句和和弦经常**半音化移动
  （chromatic movement）**。
- 乐句结尾常用**下行增和弦琶音（descending augmented arpeggios）**收尾，是他很个人化的一个签名手法。

### 代表作品：不只是《Virtuoso》

- **《For Django》（1964）**：四重奏编制，向 Django Reinhardt 致敬的专辑，是他早期风格的代表。
- **《Virtuoso》（1973）**：公认他最重要的作品，也是公认的爵士吉他独奏专辑标杆之一——11 首标准曲 + 1 首原创，
  同时弹出旋律、和弦、低音，被乐评形容为"听起来不止一把吉他在演奏"。后续还有 *Virtuoso #2/#3/#4* 延续这个概念。
- **与 Ella Fitzgerald 的二重奏**：两人在 Pablo 厂牌合作了 6 张专辑——*Take Love Easy*（1973）、
  *Fitzgerald and Pass... Again*（1976，为 Ella 拿下 1977 年格莱美最佳爵士人声专辑）、*Hamburg Duets 1976*、
  *Sophisticated Lady*（1975/1983）、*Speak Love*（1983）、*Easy Living*（1986）——只用一把吉他伴奏一位
  歌手撑起整首曲子，本身就是 chord melody 实战能力的最好证明。
- **与 Oscar Peterson 的合作**：《The Trio》(1974，与贝斯手 Niels Pedersen)、《The Giants》(1974，与
  Oscar Peterson、Ray Brown)、《Porgy and Bess》(1976)、《The Paris Concert》(1978) 等——他也是一位极强的
  伴奏乐手，不只是独奏专才。

### 教材

- **《Joe Pass Guitar Style》**（与 Bill Thrasher 合著）：分"和声"（和弦构造/装饰/替代/连接/对称和弦）和
  "旋律"（和弦音阶、改变音阶、耳朵训练、全音阶、和弦解决、布鲁斯等）两大部分，是他最系统的一本方法书。
- **《Joe Pass Chord Solos》**：专门讲"如何即兴弹出和弦式独奏"，附大量他本人的实际弹奏范例分析。

### 从哪里开始学

先听《Virtuoso》整张专辑建立耳朵印象（这是他风格最浓缩的一张），再配合《Joe Pass Guitar Style》从"三音和弦
→ 声部连接 → 加旋律"的顺序练习，会比直接扒谱轻松很多——他的东西即兴成分很重，直接扒谱容易只学到表面指法。

## 4. Ted Greene 深度介绍

### 生平

Ted Greene（1946–2005），出生并活跃于洛杉矶，11 岁开始自学吉他，中学时期就已经是能上台跟 R&B 乐队合作的
水平。他一生只录过一张录音室专辑（*Solo Guitar*，1977），公众知名度不算高，但在吉他手圈子里被奉为和声理论
的"圣人"级人物——他本人对公开演出/成名兴趣不大，重心几乎全部放在私教和写讲义上。

### Chord Chemistry：他的成名作

**《Chord Chemistry》（1971）** 被广泛称为"爵士吉他手的圣经"——系统地把大三、小三、属七、减七、增和弦等
每一类和弦的构造原理和转位方式讲透，核心目的是让吉他手在指板上找到平滑的声部连接。这本书之所以经典，是因为
Ted Greene 本人**大量阅读"共同实践时期"（约 1600–1900 年，古典和声理论成型的年代）的乐理著作**，把这些
原本写给键盘/作曲的复杂理论"翻译"成吉他手能直接用的形式——这也是他和 Joe Pass 最大的区别：Joe Pass 的东西
是"演奏家的直觉"，Ted Greene 的东西是"教育家的系统化"。

### 教学生涯

除了写书，他还在 GIT（Guitar Institute of Technology）开讲座、在《Guitar Player》杂志开专栏，私教是他教学
生涯的主体——这也是为什么他留下的免费遗产格外丰富（见下）。

### 独奏吉他技巧

- **竖琴式琶音（harp-like arpeggios）**：让和弦音一个个滚出来而不是同时弹响，制造出竖琴一样的音色。
- 配合轻柔的**颈部揉弦（neck vibrato）**制造出他招牌的"shimmer"（微微颤动的光泽感）音色。
- 跟 Joe Pass 类似，也会同时弹**走动低音 + 旋律**，但整体触感更内敛、更"古典"，不像 Joe Pass 那样即兴感强烈。

### 免费遗产：tedgreene.com

他去世后，学生们把他留给每个私教学生的**手写讲义**陆续扫描上传到 [tedgreene.com](https://tedgreene.com)，
现在这个官方存档站点上有**超过 2400 份免费课程/讲义/改编谱/录音**，涵盖 chord melody、声部连接、把键盘和声
"翻译"到吉他指板等主题，而且还在持续按季度更新——这是这两位里唯一一份**完全免费、体量巨大**的第一手教学资料。

### 教材

- 《Chord Chemistry》（1971）——上面介绍过，理论地基。
- 《Modern Chord Progressions Vol. 1》（约 1976）——和弦进行专项。
- 《Single Note Soloing Vol. 1 & 2》——单音线条即兴专项，弥补 Chord Chemistry 只讲和弦、不讲单音 solo 的部分。

### 从哪里开始学

免费资源体量巨大，容易迷路——建议先去 tedgreene.com 直接搜 "shell voicing" 或 "drop 2" 这类关键词找对应的
讲义入门，而不是想着"从头看到尾"；系统学的话再补《Chord Chemistry》打地基。

## 5. 两人怎么比

| | Joe Pass | Ted Greene |
|---|---|---|
| 身份 | 职业演奏家，也是极受欢迎的伴奏乐手 | 私教/理论家，公众演出录音极少 |
| 风格底色 | 即兴驱动，Django + Bebop 血统 | 理论驱动，古典和声"翻译"到吉他 |
| 最佳入门作品 | 《Virtuoso》（1973 专辑） | 《Chord Chemistry》（1971 教材） |
| 免费程度 | 教材需要购买 | tedgreene.com 有 2400+ 份免费讲义 |

## 6. 接下来往哪条线深挖

按口味挑一条继续走，不用把整条谱系都学一遍：

- **喜欢即兴自由、演奏家气质**：Joe Pass → 再往前追到 Django Reinhardt、Lenny Breau（泛音技巧更极端）。
- **喜欢系统理论、想按教材一步步来**：Ted Greene → George Van Eps 的《Harmonic Mechanisms for Guitar》
  （比 Chord Chemistry 更进阶，专讲他的 7 弦"lap piano"技法）。
- **想要当代、教学法最新、坡度最平缓的入口**：Martin Taylor 的《Beyond Chord Melody》系列——他本人还在世
  授课，教材是这条谱系里更新最及时的。
- **想听声部连接的"另一种活法"**（不想全学 drop2/drop3 那套标准公式）：Ed Bickert。

不管走哪条线，地基都是同一个东西——**shell voicing（壳和弦）**：只用根音+三音+七音的三音和弦，是所有人
"同时弹旋律+和声+低音"打法共同的骨架。这部分整理成了单独一篇：[shell-chords-guide.md](shell-chords-guide.md)。
