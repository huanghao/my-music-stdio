# Licks 课程集与训练配置

课程集把有顺序的一组 Lick 收纳在一起。每条 Lick 仍然独立保存目标速度、训练配置和练习记录；课程集本身只负责组织，不合并各课的进度。已有独立 Lick 无需迁移。

谱条用于直接练习，PDF 用于下载和批注，视频用于示范。个人目标 BPM（每分钟拍数）与视频速度范围分开保存，视频最高速度不会自动成为个人目标，也不会自动判定掌握。

## 找到和组织练习

首页显示最近练习的三条内容，课程集首次默认折叠；展开后按课程序号排列，不随最近练习时间改变。搜索、筛选及各面板的展开状态会在刷新后恢复，保存在本机 `localStorage`（浏览器本地存储）中。搜索结果临时展开课程集，不改变清除筛选后的展开偏好。独立 Lick 中不再重复显示已出现在“继续练习”中的条目。

搜索可以匹配标题、课程集名和技巧标签，也可以叠加状态、技巧筛选。详情页提供上一课、下一课和状态切换。“在练、待练、维护、归档”是手动组织状态，达到目标速度不会自动改状态。

编辑页的“课程归属与训练配置”可以填写课程集、序号、标签和状态。课程集留空即可作为独立练习，使用相同名字会归入同一课程集。

## 练习一课

详情页依次显示核心谱条、练习说明、节拍器、收起的示范资料和练习历史。播放由原有底部 Play 控制。

每课分别记住起始 BPM、个人目标、提速步长、拍号、细分、一轮小节数、每档轮数、自动提速及折返设置。重新进入时，当前速度优先恢复上次练习值，首次进入使用本课起始速度。切换课程会停止节拍器，避免上一课的节拍继续运行。

例如四小节练习设置每档两轮，自动提速开启后每八小节加速；八小节练习设置每档三轮，则每二十四小节加速。自动提速默认关闭，可先手动确认完整弹好再加速。

节拍器细分支持四分、八分、十六分音符，以及三连音、六连音。它决定辅助点击的密度，不改变谱面的音符时值。导入的十课默认使用四分音符点击。

练习历史仍记录练习时长和速度，不代表已确认稳定掌握。原有的自动计时和记录规则保持适用。

## 示范和材料

“示范与参考资料”默认收起，包含本地带声音的视频、原始来源链接以及 PDF。点击“批注谱子”使用原有 PDF 查看器；编辑页可以替换谱条图片和材料地址。

交替拨弦提速十课的材料与 Lick 数据位于 `~/workspace/my-store/my-music-stdio-data/` 下，由实际偏好设置中的 `licks_dir`、`materials_dir` 决定。视频提谱的中间数据位于该目录下的 `video-tabs/speed-lessons/`。

首次导入默认第一课“在练”、其余九课“待练”。起始个人目标是可调整的初始设置，不是能力评估。

## 重新导入

仓库提供 [`scripts/import_picking_course.py`](../scripts/import_picking_course.py)，输入为已经审核的谱条、单课 PDF、播放列表和合并声音后的视频。服务运行时执行：

```bash
.venv/bin/python scripts/import_picking_course.py
```

可以使用 `--source` 指定素材目录，使用 `--base-url` 指定服务地址。脚本通过本地 API（应用程序接口）创建记录；按课程集和来源链接跳过已有课程，不覆盖个人目标、配置或练习历史。文件按内容散列复用，避免重复上传相同材料。

服务端普通编辑只更新请求中出现的字段，因此旧客户端修改笔记不会清除课程信息。训练配置独立保存，写入与练习历史更新串行处理，文件原子替换，避免快速切课或并发记录时丢失数据。
