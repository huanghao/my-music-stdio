# 调性和声地图：从三大功能组，到你已经问过的所有具体手法

这篇不讲新知识——**这篇的作用是把你已经学过的东西挂到一个骨架上**。你之前的提问方式是"这个是什么，
解释一下"，问一个答一个，但每个手法之间的关系没有人替你画出来过。这篇就是画这张图。

## 0. 一句话总纲

**所有和声手法，本质上都是"三大功能组"上的某种操作。** 记住这一句，后面的一切都是细节：

> T（主）→ S（下属）→ D（属）→ T 是骨架，你学过的每个具体手法，
> 要么是在**某个功能组内部**换和弦，要么是在**临时伪造/加强/替换/绕开**某个功能组，
> 要么是**换掉整个骨架所在的调**。

## 1. 地基：三大功能组

这部分 [和弦进行入门 §3](chord-progressions-guide.md#3-为什么某些和弦想要解决到另一个和弦功能和声)
已经讲过，这里只放速查表，细节回那篇看：

| 功能组 | 大调级数 | 角色 |
|---|---|---|
| T（主功能组，Tonic） | I, vi, iii | 稳定、可以停 |
| S（下属功能组，Subdominant） | IV, ii | 过渡、准备离开 |
| D（属功能组，Dominant） | V, vii° | 紧张、必须解决 |

小调对应：i/VI/III 是 T，iv/ii° 是 S，V（和声小调，升七级）/vii° 是 D。

**关键认知**：T-S-D 是"和弦扮演的角色"，不是"和弦本身"。V7/ii（比如 C 大调里的 A7）扮演的角色
是"Dm 的临时 D"，它不是 C 大调 T-S-D 体系里的成员，是**临时借来的另一套 D**——这个区分是理解
下面所有手法的关键。

## 2. 骨架之外的第二条独立规律：根音怎么移动

功能组回答"这个和弦扮演什么角色"，但完全不管"根音具体怎么走"。根音移动是另一条**独立的轴**，
见 [和弦进行入门 §4](chord-progressions-guide.md#4-生成逻辑所有进行其实来自-3-4-个基础模型)：

- **五度圈链**（根音每步纯五度下行）——ii-V-I 是最短的一条
- **级进链**（根音每步只挪一个音阶步）
- 两条规律经常**重合**（ii→V→I 既是"S→D→T"又是"五度圈"），重合时听感格外顺，这不是巧合，
  是两种"顺耳的理由"叠在了一起。

## 3. 每个具体手法，都是对某个功能组做的一种操作

这张表是这篇文档的核心——把 [和声进阶](chromatic-harmony-and-substitutions.md) 和之前问答里
出现过的每个手法，按"操作对象是谁、做了什么"归类：

| 手法 | 操作对象 | 具体做了什么 |
|---|---|---|
| **功能替代**（vi 代 I，ii 代 IV……） | 组内部 | 换成同组另一个和弦，共享 2 音，骨架不变，换个味道 |
| **附属和弦**（V7/ii, V7/V……） | 临时伪造一个 D | 借"目标和弦自己的属"，制造一个只存在一瞬间、不属于本调 T-S-D 的临时 D，专门推向某个目标 |
| **套娃式属和弦链**（iiø7/ii-V7/ii-ii） | 临时伪造 S→D | 在临时 D 前面再加一个临时 S（目标自己的 ii），把"临时推力"从一步延长成两步 |
| **三全音代理**（subV7） | 换 D 的替身 | 还是属功能，只是根音换成三全音外的另一个属七，贝斯线从跳进变半音 |
| **V9sus4** | 削弱 D | 属和弦的 3 音（导音）换成 4 音，张力被拔掉大半，D 还在但不"急" |
| **借用和弦**（iv, ♭VI, ♭VII, ♭III, ii°……） | **跳出**本调的 T-S-D | 不属于这三个组任何一个，是从平行小调整体搬来的颜色，不追求解决 |
| **后门进行**（ivm6-I, ivm7-♭VII7-I） | 绕开 D，改走别的路到 T | 不走"D 解决到 T"这条正门，借用小调的 S（iv）另开一条通到 T 的后门 |
| **假终止**（V-vi） | D 正常解决，但 T 被调包 | D 的推力没变，只是落地的"T"从 I 换成了同组的 vi |
| **"刹车和弦"**（V-♭VI） | 假终止的加强版 | 同上，但落地的和弦换成**不属于本调**的 ♭VI，意外感更强 |
| **关系大小调转移**（G 大调↔E 小调） | 换掉整套 T-S-D 坐标系 | 不是操作某一个和弦，是把"哪个音是家"整体挪到另一个音，一整套 T-S-D 跟着搬家 |

看这张表就能看出一条隐藏的难度递增线：**组内替代最温和（还在同一个家里换沙发）→ 临时伪造/加强 D
次之（出门办点事再回家）→ 借用和弦/后门/刹车更远（去邻居家串门）→ 关系调转移最彻底（直接搬家）**。

## 4. 遇到一个没见过的和弦，怎么归类——一套判断步骤

下次再看到一条陌生的和弦进行，不用再点状提问，按这个顺序问自己：

1. **先确定"家"在哪**：整条进行的主音是谁？（听哪个和弦最像"结束点"）
2. **对着这个主音，把每个和弦标成级数**：能对上 I/ii/iii/IV/V/vi/vii° 里的某一个吗？
   - 能 → 看它是 T/S/D 哪一组，大概率是**功能替代**或**根音移动**（五度圈/级进），不需要更复杂的解释。
3. **对不上任何一级，但下一个和弦是本调的某个音**：它是不是"下一个和弦的属"（根音比下一个和弦
   高纯五度，且是大三小七）？
   - 是 → **附属和弦**。前面还带一个像 ii 的和弦（小七或半减七）？→ **套娃式属和弦链**。
4. **对不上任何一级，但根音在"预期的属和弦"三全音外**：
   - 是 → **三全音代理**。
5. **对不上任何一级，但它是从同主音小调借来的**（比如大调歌里冒出个 Fm、Ab、Bb）：
   - 是 → **借用和弦**。如果这个借用和弦出现在"该走向 V 却没走"的位置 → 多半是**假终止**的调外加强版
     （"刹车和弦"）。如果出现在"贝斯半音下行走向 I"的位置 → **后门进行**。
6. **前面几步都对不上，但整段突然听起来"移调了"**：
   - 检查新的"家"是不是原调的关系大/小调（同一套音，换个主音）——**关系调转移**，回第 1 步重新
     标一遍级数。

   之外的所有具体手法，都在这篇里详细展开（原理 + 例子 + App 现状）。
3. **[Autumn Leaves 分析](autumn-leaves-analysis.md)** —— 一个真实的谱例，把"功能替代、五度圈、
   关系调转移、套娃式属和弦链、三全音代理"全部叠在一起用，照着这篇能看到这些手法在真实音乐里
   怎么组合出现，不是各自孤立的教科书例子。

   - App 导航栏「Progressions」页——自己输入级数生成示例、换调、编辑/删除、对比试听、
     查某个调里第几级是什么和弦（大调/自然小调速查表）

     `chord-progression-comparison.html`（上面表格里大部分手法的 A/B 对比试听）、
     `chord-inversion-vs-voicing.html`（转位 vs 排列法的听觉验证）
   - `chord-analysis-special-person.html`（在 `docs/` 下，和其他理论文档放一起）——方大同《特别的人》的
     真实谱例分析，逐段拆解 + 每个手法都能点了听，比 Autumn Leaves 那篇更细——把同一处和弦改一个音再对比试听

理论看不懂就去第 4 类工具里点了听；听完记不住规律就回第 1-3 类文档里找对应的那一节。
