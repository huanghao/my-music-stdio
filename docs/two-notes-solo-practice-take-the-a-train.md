# 用《Take the A Train》练 Two-Notes Solo：为什么练这三个调、怎么练

> 本文档基于用户提供的 Jens Larsen 课程字幕（原文见 [`take-the-a-train-course-transcript.txt`](take-the-a-train-course-transcript.txt)）整理，把课程里散落在三段讲解中的方法论、和声分析、具体音符选择合并成一份可复查的笔记。

## 这是不是经典练法

是的。"每个和弦只弹两个音，跟着和弦进行走一遍"是爵士吉他/即兴教学里很常见的入门套路，常被称为 **guide-tone line** 或 **two-note melody**。核心逻辑：

- 一个和弦最能定义其"色彩"和"功能"的音，通常是 3 度（决定大/小）和 7 度（决定大 7、属 7 还是半减/减 7），但**不是死规则**——下面会看到 Larsen 实际选的两个音并不总是 3+7，而是按"能不能和相邻和弦共用/挨得近"来挑。
- 相邻和弦之间选的两个音要尽量**离得近**（同音或差一个音级），这样弹出来的两音旋律听起来是"一条线"而不是"跳来跳去"。这是比"永远用 3+7"更本质的原则：**平滑连接优先于教条化的度数选择**。
- 等两音骨架稳了，再逐步加经过音、装饰音，最后才是"自由即兴"——这是一个**从骨架到血肉**的渐进训练法，而不是让你永远只弹两个音。

库里的 PDF 材料（`Chapter2 Playing the Changes Two Notes at The Time and Keeping the Form`，作者 Jens Larsen）用的就是这个方法，说明这不是临时编的练习思路，是有教材依据的标准套路，而且字幕里 Larsen 自己也强调：这门课真正要教的不是"会弹这首曲子"，而是**教你一套自己拆解任何一首新曲子、找到练习材料、想出怎么在上面即兴的方法**——《Take the A Train》只是拿来演示这套方法的载体。

## 《Take the A Train》的和声结构（PDF 教材版本）

PDF 里用的是简化后的 lead sheet 版本（跟 Ellington 原版的 C6/D9 记法功能等价，只是把 6 和弦记成 maj7、把 D9 记成 D7）：

**A 段**：
```
Cmaj7 | D7 | Dm7 | G7 | Cmaj7 | G7
```
（第二遍 A 段结尾把 `G7` 换成 `C7`，作为转桥段的副属和弦）

**B 段（桥段，PDF 只给了前半）**：
```
Fmaj7 | D7 | Dm7 | G7(♭9)
```

## 曲子分析方法：先看大局，再补细节

字幕第三段（曲子分析视频）示范了 Larsen 拆解任何一首 standard 的通用套路——**先问两个问题：调性是什么？曲式是什么？** 答案定了，剩下都是往里面填细节：

- **曲式**：32 小节 **AABA**。既然 A 段和 B 段各出现两次（B 只有一次但结构统一），只需要吃透一个 A 段和一个 B 段，全曲就分析完了。
- **调性**：**C 大调**。

**A 段**：`Cmaj7`（主和弦 I）→ `Dm7`（ii）→ `G7`（V）——这三个都是 C 大调的自然和弦，不需要额外音阶。唯一需要多想一步的是 `D7`：D 不在 C 大调音阶里，但它是一个**属和弦**，解决到 C 大调的另一个属和弦 G7 上——这就是所谓"**属和弦的属和弦**"（dominant of the dominant，也叫 **V/V，属方向的副属和弦**），大小调里都极常见，要能一眼认出来。既然它解决到大和弦 G，就可以直接把它当成 **G 大调里的一个 D 和弦**来处理，所以要用 **G 大调音阶**。

第二遍 A 段唯一的差异是结尾换成了 `C7`：同样是副属和弦，这次解决到 `Fmaj7`（C 大调的 IV 级），于是把它当成 **F 大调里的一个 C 和弦**，用 **F 大调音阶**。

**桥段（B）**：`Fmaj7` 就是 C 大调的 IV 级（下属），不需要新音阶；接下来的 `D7` 是同一个"属方向副属和弦"（A 段已经练过）；最后 `Dm7-G7` 是回主调的 ii-V（也已经练过）。所以桥段没有引入任何新素材，全靠前面 A 段分析出的两个借用音阶就能盖住。

**结论**：全曲绝大部分时间用 **C 大调音阶**就够，只有两个"离家出走"的瞬间需要额外准备——**G 大调**（应付 A 段的 D7）和 **F 大调**（应付第二个 A 段结尾的 C7）。这就是为什么练习顺序是 C（已有基础）→ G（用得最多，先练）→ F（同结构，练起来更快）。

## 练习顺序与节奏安排（课程原话）

Larsen 在字幕第一段里给的具体节奏建议：

1. **C 大调**：Chapter 1 已经在练的音阶 / 3 度音程 / 三和弦 / 自然七和弦（diatonic 7th chords），先确保这个打底扎实。
2. **一次只加一个新调**，不要 G、F 同时上手。**优先练 G 大调**（曲子里用得更多），按和练 C 大调一样的顺序重新走一遍：**音阶 → 3 度音程 → 三和弦 → 七和弦**。
3. G 大调走熟之后再加 **F 大调**，走同样的四步——Larsen 特别提到，**这一步会比练 G 大调快**，因为流程已经跑熟了，而且吉他上的把位/指型和 G 大调也很接近。
4. **时间不够时的变通**：不必每天三个调都练一遍，可以按天轮换（周一 C、周二 F、周三 G，循环），但**前期还是建议先把 Cmaj7 练到很舒服**，再开始加另外两个调的练习。
5. 除了音阶体系，这一章还有两条同样重要的线：**学旋律**（技术上有一点挑战，但曲子速度友好，应该能拿下）和**用两音组即兴**（下一节详述）——这两者是同步进行、互相加强的，学旋律时练到的目标音，正好就是两音即兴要用的那些音。

## 两音练习：具体用哪两个音（课程原话逐和弦拆解）

字幕第二段给出了 Larsen 自己弹的两音旋律具体音符。注意他**没有教条地统一用"3 度+7 度"**，而是每个和弦挑一对**离前后和弦最近、能尽量共用**的两个音——这正是"平滑连接优先于度数教条"的示范：

| 和弦 | 用的度数 | 具体音 | 备注 |
|------|---------|--------|------|
| `Cmaj7`（A 段, I） | 3 度 + 5 度 | E, G | |
| `D7`（A 段, V/V） | 3 度 + 5 度 | F#, A | 和 Cmaj7 用同一个"形状"整体上移一个音级，Larsen 说他把这两个和弦"当一件事来看" |
| `Dm7`（A 段, ii） | 根音 + 3 度 | D, F | |
| `G7`（A 段, V） | 5 度 + 7 度 | D, F | **和 Dm7 用的是同一对音**——ii 与 V 之间几乎零移动，这是最典型的"共用音连接"手法 |
| `Cmaj7`（回到 A 段开头） | 3 度 + 5 度 | E, G | 循环回第一个和弦 |
| `G7`（第一遍 A 段结尾） | 5 度 + 7 度 | D, F | 同上 |
| `C7`（第二遍 A 段结尾，V/IV） | 5 度 + 7 度 | G, Bb | 把 A 段带去桥段 |
| `Fmaj7`（桥段, IV） | 3 度 + 5 度 | A, C | 和 Cmaj7 同结构（3+5），只是整体挪到 F |
| `D7`（桥段, V/V） | 3 度 + 5 度 | F#, A | 和 A 段的 D7 完全一样 |
| `Dm7`（桥段, ii） | 根音 + 3 度 | D, F | 和 A 段的 Dm7 完全一样 |

可以看到全曲实际只用了 **5 组音**（E-G、F#-A、D-F、G-Bb、A-C），而且很多和弦直接复用同一组——这就是课程反复强调的"**离得近、少跳动**"：与其每个和弦都现学一对新音，不如设计一条尽量共用音符的路线，弹起来才像一条自然的旋律线，而不是机械地"报和弦音"。

## 三全音解决：为什么 G7 想去 Cmaj7（图解）

上表 `G7 → Cmaj7` 这一步能听起来"非解决不可"，根源是 G7 的 3 度音（B）和 ♭7 度音（F）之间正好差 **6 个半音**——八度（12 个半音）的正中间，也就是**三全音（tritone）**，十二个音程里最不稳定的一个。这两个音各自又只比目标和弦里的邻近音差半音，于是同时释放、往两边收拢：

```
半音阶（从 B 数到 F）：

   B ── C ── C# ── D ── D# ── E ── F
   |    ▲                     ▲    |
   |____|                     |____|
   升半音                      降半音
  (B → C：导音 → 主音)       (F → E：♭7度 → 3度)

   └──────────── 三全音 = 6 个半音 ────────────┘
        (G7 的 3 度音 B 到 ♭7 度音 F)

解决之后：

   C ─────────────────────────── E
   └────── 大三度 = 4 个半音 ──────┘
   (Cmaj7 的根音 C 到 3 度音 E，协和、稳定)
```

逐音对照，四个和弦音各自的去向和"必须动 vs 可以不动"：

| G7 里的音 | 角色 | → | Cmaj7 里的音 | 角色 | 动作 |
|---|---|---|---|---|---|
| B | 3 度（导音） | → | C | 根音 | **必须**升半音——这条不走，解决感就没了 |
| F | ♭7 度 | → | E | 3 度 | **必须**降半音——跟 B 一起动，才把三全音收拢成大三度 |
| G | 根音 | → | G | 5 度 | 可以不动，本来就是共同音 |
| D | 5 度 | → | (D) | 9 度/装饰音 | 自由，留不留都行 |

B→C、F→E 这两条是硬拉力，决定了"这是不是一次 V→I 解决"；根音和 5 度则相对自由，这也是为什么前面说"目标和弦具体是 Cmaj7 / C6 / C9 都行"——只要接住 B 和 F 这两条线，上面盖什么色彩是自由的。

> 三全音还有另一个更进阶的用法——**三全音代理**（用根音在三全音外的另一个属七和弦替换 G7，比如 Db7），因为任何两个根音相差三全音的属七和弦都共享同一组 3-7 音。这部分不在本文范围内，详见 [和声进阶：附属和弦、三全音代理、借用和弦](chromatic-harmony-and-substitutions.md#2-三全音代理tritone-substitution)。

## 附：Ellington/Strayhorn 原版和弦色彩（比 Larsen 简化版更丰富）

Larsen 教材用的是"教学简化版"（`Cmaj7`、`D7`、`Dm7`、`G7`……），方便你先抓住和声骨架。但实际乐队谱/Real Book 上常见的版本会用更丰富的和弦色彩——**和声功能完全一样**（前面"曲子分析方法"那节的 ii-V-I、副属和弦分析照样成立），只是每个和弦上"穿的衣服"更华丽。常见写法大致是（不同乐谱在个别和弦上略有出入，骨架一致）：

**A 段**：
```
C6 | D7(♯11) | C6 | D7(♯11) | C6 | D7(♯11) | Dm7 G7 | C6
```

**B 段（桥段）**：
```
F7 | F7 | F#dim7 | F#dim7 | C6/G | A7 | D7 | G7
```

其中第 3-4 小节的 `D7(♯11)` 是全曲最出名的一个和弦——旋律音恰好落在那个升十一度音上，这个 **Lydian dominant** 音响是爵士教材里讲副属和弦和 Lydian dominant 音阶时的标配例子（详见 [《Take the A Train》的历史](take-the-a-train-and-cartoon-jazz.md#和声为什么弹爵士的人都绕不开它)）。

**跟 Larsen 简化版逐一对照**：

| Larsen 简化版 | 原版丰富色彩 | 差在哪 |
|---|---|---|
| `Cmaj7` | `C6` | 把 7 度音（B）换成 6 度音（A） |
| `D7` | `D7(♯11)` | 加了一个升四/十一度音（G♯），同一个副属和弦，色彩更亮 |
| `Dm7` | `Dm7` | 不变 |
| `G7` | `G7` | 不变 |
| `Fmaj7`（桥段） | `F7` | 把大七度（E）换成小七度（Eb），IV 级和弦染上一点属和弦色彩 |
| （无） | `F#dim7` | 桥段里新增的**过渡和弦**，Larsen 版没有这一步 |
| （无） | `C6/G` | 斜线和弦，同一个 C6 和弦但低音换成 G |

**几个新出现的和弦类型是什么**：

- **6 和弦（如 `C6` = C-E-G-A）**：三和弦上加一个大六度音，不是七和弦（`Cmaj7` = C-E-G-**B**，`C6` = C-E-G-**A**）。摇摆时代（1930-40 年代，正是 Ellington 乐队活跃的年代）的大乐队谱里，主和弦、下属和弦几乎默认写成 6 和弦而不是 maj7——因为 maj7 的 7 度音（B）离根音（C）只差半音，贴得太近，听感比较"现代/尖锐"；6 和弦更圆润、更"摇摆年代"。**`C6`（C-E-G-A）和 `Am7`（A-C-E-G）不只是巧合同音，严格说 `C6` 就是 `Am7` 的第一转位**——把 Am7 原位（A-C-E-G）的 3 度音 C 挪到最低音，就是 C-E-G-A，跟 C6 写法完全一样。四个音没变，区别只在于低音落在 C 还是 A、前后文让耳朵往哪边听——低音在 C、语境是主和弦，听感就是 C6；低音在 A、语境是 vi 级或 ii-V 的一部分，听感就是 Am7。实用结论：吉他上已经会的 Am7 指型可以直接当 C6 弹，不用另学一个"C6 专用指型"。
- **9 和弦（如 `D9` = D-F♯-A-C-E）**：属七和弦（`D7` = D-F♯-A-C）上再加一个九度音（E，也就是二级音移高一个八度）。功能跟 `D7`完全一样（还是解决到 G），只是声音更饱满、更"甜"。
- **♯11（如 `D7(♯11)`）**：在属七和弦上加一个**升高的十一度音**（这里是 G♯，即四级音升半音后再移高一个八度）。这个音跟和弦里的五度音（A）只差一个全音，贴得很近，会产生一种明亮、飘浮、略带现代感的色彩，这个音阶被称为 **Lydian dominant**（属七和弦配合升四级的一种调式音阶）。这不只是一个和声选择——Strayhorn 把旋律音直接写在这个音上，所以这个色彩是刻在曲子骨子里的，不是可选装饰。**跟 sus4 不是一回事，虽然都涉及"第四级"**：sus4（如 `D7sus4` = D-**G**-A-C）是把 3 度音（F♯）整个**换掉**，换成还原的纯四度 G，和弦因此没有大小调属性，听感悬空、模糊；♯11 是**保留 3 度音（F♯）不动，另外加一个升高的四度（G♯）**，F♯ 和 G♯ 同时存在、只差半音贴在一起摩擦，听感是明亮带点"刺"。两者用的还是不同的音（G 还原 vs G♯升高），不是同一堆音的两种写法，效果也刻意相反：sus4 抹掉棱角、♯11 加一道锋利的边。
- **全减七和弦，用作过渡和弦（如 `F#dim7`）**：由连续小三度堆起来的和弦（F♯-A-C-Eb），本身高度对称、不稳定。它在 `F7 | F#dim7 | C6/G` 这三个和弦之间干的具体活是：低音线 F→F♯→G 半音爬升，`F#dim7` 就是给中间这个过渡低音配的和弦。把它的四个音和目标和弦 `C6`（C-E-G-A）对齐看：F♯→G（升半音）、**A 不用动**（两个和弦共用）、**C 不用动**（两个和弦共用）、Eb→E（升半音）——四个音里两个完全共用、另外两个各自只差半音就到位，几乎不用挪窝就顺滑接上了下一个和弦，这正是减七和弦这种"堆小三度"的对称结构天生适合当连接和弦的原因。多说一句：`F#dim7`（F♯-A-C-Eb）去掉根音再补一个根音 D，就是 `D7(♭9)`（D-F♯-A-C-Eb）——跟前面 `G7(♭9)` 是同一类和弦。这不是巧合，任何减七和弦都可以看成"某个属七♭9 和弦去掉根音"，因为它高度对称，随便挑其中一个音当"3 度"往下推大三度补根音都成立，所以 `F#dim7` 同时是"过渡和弦"和"隐藏了根音的副属和弦"两种身份。
- **斜线和弦（如 `C6/G`）**：写法是"和弦名/低音"，意思是"弹 C6 这个和弦，但低音用 G 而不是 C"。和弦本身的功能不变（还是主和弦 C），只是为了让低音线走得更平滑（比如从上一个和弦的低音接过来更顺）而换了一个低音音符——纯粹是编配/声部进行层面的技巧，不影响你之前学的和声功能分析。

**对你现在的练习有没有影响**：**没有，可以先不管**。你练的两音引导音、曲子分析里的 ii-V-I 和副属和弦逻辑，在这个丰富版本上照样成立——`C6` 依然是 `1` 级，`D7(♯11)` 依然是"临时挪到 G"的那个副属和弦，只是和弦上多穿了件衣服。这一节是给你"知道以后可能会在乐谱上看到什么、那是什么意思"用的，不需要现在就把两音练习换成这些和弦。

## 练习步骤

1. **音阶体系打底**：按上面"练习顺序"分别把 C（已会）→ G（优先）→ F 走完"音阶 → 3 度 → 三和弦 → 七和弦"四步。
2. **学旋律**（PDF "Learning The Melody"）：照谱弹一遍 A 段 + B 段的原曲旋律骨架，建立"这段和弦听起来该长什么样"的耳朵参照——这一步和下一步是同步进行、互相强化的。
3. **两音练习，先固定节奏跑一遍**（PDF "The Two Note Exercise"）：按上表的音符，每小节弹一次，先只是"听个响"，建立这套音听起来是什么效果的预期。
4. **弹 Larsen 的两音 solo 范例**，再开始**用同一批音自己即兴**：配合 backing track 或节拍器，重点放在**节奏和律动**（swing、groove）上而不是纠结选哪个音——音已经限定好了，脑子腾出来专注"怎么让它摇摆起来"。刚开始弹起来会很机械（一直在想"我在哪个和弦、该用哪两个音"），这是正常的，多练几遍会自然消失。
5. **加连接音，扩展成自由即兴**：两音骨架稳定后，在两个引导音之间加经过音，从"两音"变成"三音、四音旋律"——加的音从当前和弦对应的大调音阶里借（C 段用 C/G 大调音级，F 段用 F 大调音级），逐步过渡到不再有"两个固定音"的限制、完全自由的即兴。
