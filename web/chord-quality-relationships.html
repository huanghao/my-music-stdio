1) 八个级数按半音从低到高竖着排开

根音 三度类（b3 / 3） 五度类（b5 / 5） 七度类（bb7 / b7 / 7）
竖轴是半音数（从下往上 0~12，最上面 12 就是高八度的根音）。可以看到 b3 和 3 只差一个半音， b5 和 5 只差一个半音，bb7、b7、7 是连续三个半音（bb7=9, b7=10, 7=11）—— 这也是为什么 bb7 听起来"就是"一个全音阶记法古怪的 6 度音，实际按半音算跟 b7 只差一步。

2) 五种七和弦性质——每一步只移动一个音（降半音）

这五个和弦排成一条链：maj7 → 7 → m7 → m7b5 → dim7，相邻两列之间只有一个音差半音， 其余音完全不变（图中灰色虚线是"没变的音"，红色斜线是"这一步降了半音的那个音"，箭头指向下方—— 降半音在竖排图里就是"往下移一格"）：
• maj7 → 7：只把 7 度从大七（7）降成小七（b7）——这就是"大七和弦"变"属七和弦"。
• 7 → m7：只把 3 度从大三（3）降成小三（b3）——属七变小七。
• m7 → m7b5：只把 5 度从纯五（5）降成减五（b5）——小七变半减七（导七的感觉）。
• m7b5 → dim7：只把 7 度从小七（b7）再降成减七（bb7）——半减七变全减七。
你给的顺序是 maj7, 7, m7b5, dim7, m7——这个顺序里 7→m7b5、dim7→m7 都要同时改两个音， 不是"一步一动"关系，所以我按 maj7 → 7 → m7 → m7b5 → dim7 这个真正"每步只挪一个音"的顺序画， 这样比较容易记：全程只有 7 度、3 度、5 度轮流被降半音，而且降的顺序是 7 度 → 3 度 → 5 度 → 7 度，等于把每个音依次往下"拧紧"一格。

3) 另一个看法：dim7 是"每三个半音一个音"的对称和弦

dim7 = 0, 3, 6, 9——四个音之间全部相隔 3 个半音，是十二个半音里唯一"完全对称"的七和弦（转位后还是 dim7 和弦，只是换了个根音的叫法）。m7b5 = 0, 3, 6, 10，可以理解成"把 dim7 最高音抬高一个半音"； 反过来 dim7 也可以理解成"m7b5 把最高音再压低一个半音"——跟上面链条里 m7b5 → dim7 那一步是同一件事， 只是这里换个角度看：dim7 是唯一从任何一个音开始听都一样的和弦，其他四个都不是。

4) 吉他上看：隔 3 步 = 根音不动，其余三指统一挪一品

链条里降半音的顺序是循环的 7 度 → 3 度 → 5 度 → 7 度 → …，所以任意连续 3 步，一定会把 7 度、3 度、5 度这三个音各碰一次、且只碰一次。结果就是：凡是在链条上相隔 3 格的两个和弦 （maj7↔m7b5，或 7↔dim7），根音完全不动，其余三个音统一各降半音——如果这三个音分别按在 不同弦上，吉他指型上就是"根音那根手指不动，其他三根手指整体往品丝方向挪一格"，不需要重新记指型， 挪一下就行。

对比一下"隔几步"的效果差别就很清楚：隔 1 步（比如 maj7→7）只需要动一根手指；隔 2 步（比如 maj7→m7）要动两根手指，但幅度还都是 −1 半音；隔 3 步（maj7→m7b5、7→dim7）三根手指都要动， 但依然统一是 −1 半音，所以整体感觉像"平移"；隔 4 步——也就是链条首尾 maj7→dim7——三根手指也都要动， 但 7 度被连降了两次（共 −2 半音），3 度、5 度只降一次，幅度不统一了，就不再是简单的"平移"。

5) 补上 mMaj7：3 度、7 度各自独立开关，组成一个方格

mMaj7（小大七，1, b3, 5, 7）是小调爵士里常见的 i 级和弦，听感有点"谍战片"味道。 它跟 maj7 只差 3 度（4→3），跟 m7 只差 7 度（11→10）——正好把 maj7、7、m7 这三个 补成一个完整的方格：横向是 3 度（大三 / 小三），纵向是 7 度（大七 / 小七）。 对角线（maj7↔m7，mMaj7↔7）要同时改两个音，图上没画，因为不是"一步"关系。

m7 沿着"5 度"这个方向继续往下走，就接回卡片 2 里的 m7b5 → dim7——所以完整的关系其实是一个 3 度 × 7 度的方格，再加上从 m7 那个角往外伸出去的"5 度"这一条尾巴，一共 6 个和弦、 3 个独立方向（3 度、5 度、7 度各自升降半音）。
